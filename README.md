# KPAI Assistant

Плагин для Externagram, добавляющий ИИ-ассистента в клиент Telegram.

## Возможности

- Отвечает на сообщения через ИИ (на базе Groq)
- Поддержка выбора различных моделей
- Ищет информацию в интернете
- Распознаёт изображения

## Установка

1. Скачайте файл `kpai_assistant.plugin` из раздела [Releases](https://github.com/Liroyk1488/ai-assistant-in-tg/releases).
2. Поместите его в папку плагинов Externagram.
3. Перезапустите клиент.

## Настройка

1. Откройте настройки Externagram → Плагины → KPAI Assistant.
2. Вставьте API-ключ (Groq) в соответствующее поле.
3. Выберите нужную модель из списка доступных.

API-ключ хранится только локально на устройстве пользователя.

## Требования

- Externagram >= 12.5.1
- SDK >= 1.4.4.3
